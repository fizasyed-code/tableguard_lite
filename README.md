# tableguard_lite
Two-arm table-setting project with learned robot control and preservation-aware repair. Work in progress.
The custom two-SO-101 MuJoCo scene, camera recording, and right-arm cup grasp, transfer, placement, and release have been demonstrated in engineering trials. Left-arm fork grasp has been demonstrated, but the full fork lift-and-placement sequence remains under development.

The current robot demonstrations use scripted controllers with simulator information. SmolVLA is the selected learned-policy candidate, but task-specific training, Intel/OpenVINO policy deployment, camera-based verification, selective repair, and the final robustness evaluation are not yet demonstrated.

Successful and failed/partial recordings are labelled separately.
